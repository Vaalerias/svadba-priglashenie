# Сторонний код и происхождение starter-а

Код этого starter-а написан для AI Room Club с нуля и распространяется по лицензии MIT из файла `LICENSE`.

Репозиторий `di-sukharev/vibe` изучался как открытый пример организации проекта. Из него не копировались исходные файлы, системные инструкции, конфигурация, тексты или визуальный стиль. Мы использовали общие идеи, которые не принадлежат одному проекту: постоянный контекст рядом с кодом, маленькие задачи, проверки перед коммитом и раздельные пути для локальной разработки и production.
