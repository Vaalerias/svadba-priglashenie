# Подключение обработчика ответов

1. В Apps Script вставьте содержимое `Code.gs` и сохраните проект с названием «Свадебные ответы».
2. В настройках проекта добавьте Script Properties: `SPREADSHEET_ID` — ID созданной Google Таблицы; `FAMILY_CODES` — JSON-массив личных кодов, например `["wedding-family-demo-a"]`.
3. Разверните проект как веб-приложение: выполнять от вашего имени, доступ — у всех, у кого есть ссылка. Это необходимо, чтобы гость без аккаунта мог отправить ответ.
4. Скопируйте URL, который заканчивается на `/exec`, в `runtime-config.js` → `weddingResponse.endpoint`. Для текущей демонстрационной проверки адрес уже подключён.
5. Создавайте новый случайный код длиной не менее 16 символов для каждой семьи, добавляйте его в `FAMILY_CODES` и передавайте только в личной ссылке `?family=<код>`.

Код семьи скрыт в Таблице, но является ключом от ответа этой семьи: не публикуйте ссылки в открытом доступе.
