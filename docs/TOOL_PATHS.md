# Как выбрать рабочий интерфейс

## Основной путь

Используй VS Code и официальное расширение Claude Code или Codex. Так ты видишь файлы, план, изменения и работающий проект в одном окне.

## Запасной путь 1

Используй desktop-приложение Claude с Claude Code. Оно подходит, когда расширение VS Code не устанавливается или терминал вызывает лишний стресс.

## Запасной путь 2

Используй desktop-приложение Codex. Открой папку проекта, дай агенту прочитать `AGENTS.md` и работай по тем же задачам.

## Запасной путь 3

Запусти Claude Code или Codex CLI во встроенном терминале VS Code.

Инструмент можно менять. Файлы проекта, промпты, Git и критерии проверки остаются прежними.
