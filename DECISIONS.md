# DECISIONS.md

## 2026-07-14 — Локальный режим по умолчанию

**Почему:** участник получает первый результат без базы, аккаунтов и ключей.

**Что меняет:** база подключается только после рабочего прототипа и проверки, что данные действительно нужны.

## 2026-07-14 — Архив вместо безвозвратного удаления

**Почему:** новичок может нажать не туда. Архив безопаснее.

## 2026-07-14 — Один акцентный цвет

**Почему:** так проще сохранить визуальную иерархию во время правок агентом.

## 2026-10-21 — Ответы передаются через Google Apps Script

**Почему:** гости отправляют форму без аккаунта, а код семьи проверяется на стороне владельца до записи в приватную таблицу.

**Что меняет:** в браузере хранится только публичный адрес обработчика; ID таблицы и список разрешённых кодов остаются в Script Properties.

## 2026-10-21 — Подключение Google Таблицы для проверки главного пути

**Почему:** после локальной проверки нужно увидеть, что подготовленный обработчик записывает ответы в таблицу и заменяет строку семьи.

**Что меняет:** адрес обработчика указан в `runtime-config.js`; используются только вымышленные данные и тестовый код семьи.
