# Установка `airc-vibe-page` через Claude Code или Codex

Выбери один путь. Оба агента получают одинаковую задачу.

## Путь 1. Репозиторий уже загружен на GitHub

Открой в VS Code пустую папку, запусти Claude Code или Codex и вставь:

```text
Нужно создать новый проект из starter-репозитория AI Room Club:
https://github.com/FocusSam/airc-vibe-page

Сначала ничего не меняй в продукте.

1. Склонируй репозиторий в текущую папку.
2. Прочитай START_HERE.md, PRODUCT.md, FLOW.md, AGENTS.md и CLAUDE.md.
3. Проверь версию Node.js. Нужна 22 или новее, рекомендуемая — 24 LTS.
4. Запусти npm run doctor, npm run check и npm run dev.
5. Открой локальную ссылку и проверь основной сценарий.
6. Простыми словами объясни, какие экраны и режимы данных уже есть.
7. Пока не обновляй библиотеки, не подключай базу и не меняй архитектуру.
8. В конце задай мне вопросы из START_HERE.md и предложи первую маленькую правку.
```

## Путь 2. У тебя архив курса

Распакуй архив в отдельную папку без кириллицы в пути. Открой эту папку в VS Code и вставь:

```text
Мы работаем в распакованном starter-е AI Room Club.

Сначала ничего не меняй.

1. Прочитай START_HERE.md, PRODUCT.md, FLOW.md, AGENTS.md и CLAUDE.md.
2. Проверь, что открыта именно корневая папка проекта с package.json.
3. Проверь версию Node.js. Нужна 22 или новее, рекомендуемая — 24 LTS.
4. Запусти npm run doctor, npm run check и npm run dev.
5. Пройди основной сценарий и перечисли найденные проблемы.
6. Объясни структуру проекта простым языком.
7. Не подключай внешние сервисы и не обновляй зависимости без отдельного решения.
8. Затем проведи короткое интервью по START_HERE.md и предложи план персонализации из 3–5 маленьких шагов.
```

## Первый промпт после запуска

```text
Прочитай PRODUCT.md и FLOW.md. Нужно превратить starter в мой проект.

Мой проект: [что собираю].
Для кого: [один основной пользователь].
Полезный результат: [одно действие или изменение].
Главный сценарий: [4–7 шагов].

Сейчас сделай только персонализацию:
— название;
— короткое объяснение пользы;
— подписи главных кнопок;
— демонстрационные данные;
— один акцентный цвет.

Не меняй структуру экранов, режим данных, авторизацию и публикацию.
Сначала покажи план и список файлов. После согласования внеси изменения, запусти npm run check и отчитайся по изменённым файлам.
```

## Когда работаешь через desktop-приложение

Открой в Codex app или Claude Code desktop именно папку проекта. Дай тот же промпт из «Пути 2». Файлы `AGENTS.md` и `CLAUDE.md` держат общее ядро правил, поэтому процесс не зависит от выбранного агента.
