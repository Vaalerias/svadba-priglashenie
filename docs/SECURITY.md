# Базовая безопасность

- Работай только внутри папки проекта.
- Не вставляй секретные ключи в чат, код и скриншоты.
- Publishable key Supabase не даёт административных прав, но его безопасность зависит от RLS. Передавай его в `apikey`; `Authorization` оставляй для access JWT пользователя.
- Service-role key обходит RLS и живёт только на сервере.
- Публичная форма требует ограничения частоты перед реальным запуском.
- Архивируй записи вместо мгновенного удаления.
- Проверяй доступ минимум двумя аккаунтами.
- После утечки ключ нужно отозвать, а не только удалить из файла.
