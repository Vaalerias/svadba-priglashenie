# Как превратить starter в свой продукт

Меняй проект слоями.

**Сначала смысл.** Название, пользователь, полезный результат, главное действие.

**Потом сценарий.** Какие шаги проходит человек и что видит после каждого.

**Потом данные.** Что действительно нужно запомнить.

**Потом внешний вид.** Референсы, иерархия, мобильная версия.

**В конце интеграции.** База, вход, уведомления, оплата.

Первый промпт:

```text
Изучи PRODUCT.md, FLOW.md и текущий проект.
Нужно превратить starter в [тип продукта] для [пользователь].

Главный результат: [результат].
Главный сценарий: [3–5 шагов].

Пока ничего не меняй.
Сначала:
1. Сопоставь задачу с текущими экранами.
2. Назови, что можно переиспользовать.
3. Предложи план из 3 маленьких изменений.
4. Укажи, что точно не трогаем.
5. Дай ручной чек-лист.

После моего подтверждения выполни только первый шаг.
```
